## First comparison: search supervision

H1: A visit-distribution target retains useful alternatives that an executed
action target removes. H2: Supervision of explored action values improves the
shared representation beyond visit-policy supervision alone.

development games at 5420000000. The frozen Entity model supplies PUCT256,
depth16, world pool3, cpuct0.4, FPU reduction0.02965, zero uniform prior. Do not

random early move, cap randomization or symmetry in this first comparison.
Use independent setup, policy and encoder streams. Record all decision phases,
replay every game, and keep all blocked/capped games with no invented outcome.
Train only rows with complete outcomes and captured Main-phase search targets;
report every excluded row and its reason. Development setup IDs stay disjoint.

Save raw visit counts, Q for every visited action, explored mask, root mean Q,

Do not treat unvisited Q as a zero-value label. Hidden worlds are sampled from
Observation; real seed, deck order and opponent blind card IDs are never inputs.

onehot, visits, visits-q. All arms use value target

evaluation still uses the existing policy and value search interface. No new
trunk, tokenizer, action mapping, or Q-driven planner is permitted here.
