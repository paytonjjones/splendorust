# E94: external-teacher data boundary pilot

Hypothesis: An unchanged, demonstrably stronger external teacher can provide better supervision than repeated distillation of the weaker transferred lineage. Build the data path before a large run. Use only eight fresh AlphaZero-native self-play games at master4830000000, with two independent AlphaZero800 trees per game. Keep the pinned network, native referee and search settings unchanged. This is a data-interface pilot, not a strength experiment or model selection.

For each teacher decision, capture the acting player's public-history observation through Tracker. Pass that observation, with unknown opponent cards redacted, to the existing native policy worker's sample operation. Store its392 sampled features, native81-action legal mask, one-hot executed teacher action, selected root value, and terminal win credit in the existing2232-byte row format. Store only the seven public reservation-context fields beside each row. Use independent encoding seeds. Never put the actual opponent blind identities, native deck masks, referee RNG, setup seed as a feature, or future state into model inputs. The setup ID is split/audit metadata only. The external teacher retains its documented native private-information input; that privilege is confined to offline labels and does not alter the runtime information boundary.

On the first eight decisions of each game, compare exact public means/features from eight independent sampled encodings. Require invariance. Require every policy target legal and normalized, all feature/context values finite, complete histories replay against the unchanged referee, and exact public-observation hashes on replay. Preserve sources, model/checkpoint/worker hashes, raw game histories, dataset hashes and timing. Do not train on this pilot or on E92 evaluation games.

If the boundary passes and E92 still shows weak performance, proceed to an external-teacher training experiment with fresh train/development seeds, an explicit native profile, and separate fresh canonical checks. Do not claim a native-only gain as canonical dominance or overwrite the canonical champion merely because native strength improves.
